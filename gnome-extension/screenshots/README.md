# Screenshots for extensions.gnome.org

Drop the PNGs here before submitting (see `../PUBLISHING.md`):

- `hud.png` — the jump overlay over two windows of one app; 1280×720 or
  larger, no personal window titles or notifications.
- optionally `settings.png` — the settings window's binding list.

A headless GNOME Shell refuses `org.gnome.Shell.Screenshot`
(`AccessDenied`), so take these on a real session (`Print`, or
`gnome-screenshot -f hud.png`). Do not commit screenshots containing personal
data.
